# Lotus

אפליקציית ווב לניהול תזרים חודשי: הכנסות, הוצאות קבועות ומשתנות, וכמה נשאר להוציא עד סוף החודש.

- מותקנת למסך הבית מהדפדפן ועובדת גם בלי אינטרנט.
- כניסה עם חשבון Google. הנתונים של כל משתמש נשמרים ב-Firebase (Firestore) באזור פרטי משלו ומסתנכרנים בין המכשירים שלו. אין נתונים אישיים במאגר הזה.
- ייבוא תנועות מקובץ Excel או CSV של הבנק או חברת האשראי, ייצוא ל-CSV, גיבוי ושחזור לקובץ.
- מסך טיפים להתנהלות כלכלית ומסך הסבר על השקעה במדדים, כולל מחשבון ריבית דריבית. התוכן כללי ואינו ייעוץ.

## התקנה בפלאפון

1. פותחים את כתובת האתר בדפדפן של הפלאפון (Safari באייפון, Chrome באנדרואיד).
2. באייפון: כפתור השיתוף, ואז "הוסף למסך הבית". באנדרואיד: תפריט שלוש הנקודות, ואז "התקנת האפליקציה" או "הוספה למסך הבית".
3. פותחים את Lotus מהאייקון ומתחילים להזין נתונים שם.

## הגדרת Firebase

- Authentication: שיטת הכניסה Google מופעלת, והדומיין של האתר מופיע ב-Authorized domains.
- Firestore: הכללים שבקובץ `firestore.rules` מודבקים בלשונית Rules ומפורסמים. בלי זה אף משתמש לא יכול לקרוא או לשמור.

בתיקייה `vendor` נמצאות SheetJS (קריאת קובצי Excel) וה-SDK של Firebase, שתיהן ברישיון Apache 2.0.
