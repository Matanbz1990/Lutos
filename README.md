# Lotus

אפליקציית ווב לניהול תזרים חודשי: הכנסות, הוצאות קבועות ומשתנות, וכמה נשאר להוציא עד סוף החודש.

- מותקנת למסך הבית מהדפדפן ועובדת גם בלי אינטרנט.
- כל הנתונים נשמרים על המכשיר בלבד. שום דבר לא נשלח לשרת, ואין נתונים אישיים במאגר הזה.
- ייבוא תנועות מקובץ Excel או CSV של הבנק או חברת האשראי, ייצוא ל-CSV, גיבוי ושחזור לקובץ.

## התקנה בפלאפון

1. פותחים את כתובת האתר בדפדפן של הפלאפון (Safari באייפון, Chrome באנדרואיד).
2. באייפון: כפתור השיתוף, ואז "הוסף למסך הבית". באנדרואיד: תפריט שלוש הנקודות, ואז "התקנת האפליקציה" או "הוספה למסך הבית".
3. פותחים את Lotus מהאייקון ומתחילים להזין נתונים שם.

קריאת קובצי Excel נעשית עם SheetJS (רישיון Apache 2.0), שנמצאת בתיקייה `vendor`.
